# P-OOT
Trabalho final para a disciplina de Programação Orientada a Objetos. Estou fazendo um tocador de Ocarina baseado no jogo "The Legend of Zelda: Ocarina of Time" onde o usuário consegue tocar a ocarina, tocando músicas canônicas do jogo e criando as próprias músicas, com possibilidade de salvar para escutálas depois.
